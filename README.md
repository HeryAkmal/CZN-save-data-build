# CZN-save-data-build
Chaos Zero Nightmare Characters Build Guides merupakan website yang menyediakan informasi dan mengenai berbagai build yang direkomendasikan oleh komunitas. 
Website ini dibuat untuk membantu pemain membuat pilihan dek kartu berdasarkan build yang telah disetujui oleh komunitas.
Cara menggunakan website ini cukup simpel; Pilih karakter yang ingin di-build lalu pilih build yang ingin dipakai dari dropdown.
